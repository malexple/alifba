# Älifba — Минималистичный язык для DOS

**Älifba** — ультракомпактный интерпретируемый язык программирования для DOS/FreeDOS. Реализован как `.COM` файл размером ~4 КБ.

## Текущий статус

**Версия 0.1i** — ранний прототип. Реализованы базовые конструкции: переменные, массивы, условия, метки, функции. Многие возможности из спецификации пока отсутствуют (см. раздел "Не реализовано").

---

## Сборка и запуск

```bash
fasm alifba_v0_1i.asm alifba.com
alifba.com program.alf
```

; hello.alf — Hello World
msg = "Hello, Älifba!"

## Реализованная грамматика

### Переменные

Тип переменной определяется **контекстом первого использования**:
- Если впервые встречается в числовой операции → число (16 бит)
- Если впервые встречается в строковой операции → строка

**Переименование типа запрещено** — попытка использовать числовую переменную как строковую (и наоборот) вызовет ошибку `ERR 7` (type conflict).

Имена: до 8 символов, латиница/цифры/подчёркивания.

### Присваивание

```
; Числовое
x = 42
y = -7

; Строковое
name = "Airat"
msg = "Hello, World!"

; Арифметика (только сложение, суффикс -is)
sum = a b is          ; sum = a + b
x = x 1 is            ; x = x + 1

; Конкатенация строк (суффикс -es)
full = "Hello" "World" es    ; full = "HelloWorld"
greeting = "Hi " name es     ; greeting = "Hi Airat"
```

### Массивы

Объявление:
```
5lar scores           ; числовой массив из 5 элементов, все = 0
3ler items            ; то же самое (сингармонизм суффикса)
```

Чтение и запись:
```
scores[0] = 10
scores[1] = 20
scores[2] = scores[0]
scores[0] printka     ; выведет 10
```

Ограничения:
- Максимум 4 массива одновременно
- Максимальный размер: до 256 элементов (общая куча 256 слов)
- Индексы: от 0 до (размер - 1)

### Вывод

```
x printka             ; вывести число
"Hello" printke       ; вывести строку
msg printke           ; вывести строковую переменную
scores[0] printka     ; вывести элемент массива
```

**Важно:** суффикс должен строго соответствовать типу:
- `printka` — только для чисел
- `printke` — только для строк

После вывода автоматически добавляется перевод строки.

### Метки и переходы

**Определение метки:**
```
my_label:
    ; код после метки
```

**Безусловный переход:**
```
my_labelga            ; GOTO my_label (твёрдый)
my_labelge            ; GOTO my_label (мягкий)
```

### Функции (подпрограммы)

```
; Вызов
my_func lik           ; CALL (твёрдый)
my_func lek           ; CALL (мягкий)

; Возврат
return

; Объявление метки-функции:
my_func:
    ; тело функции
    return
```

Ограничения:
- Максимальная глубина вложенности вызовов: 8
- Функции — это просто метки + `return` (локальных переменных нет)

### Условные переходы

Формат: `<операнд> <значение><суффикс> <метка>`

| Суффикс | Смысл | Аналог |
|---|---|---|
| `saga` / `sege` | Если равно | `IF == GOTO` |
| `masaga` / `mesege` | Если НЕ равно | `IF != GOTO` |

**Примеры:**
```
; Твёрдые формы (для чисел)
port 255saga exit     ; если port == 255, перейти на exit
count 10masaga loop   ; если count != 10, перейти на loop

; Мягкие формы (для символов/строк в числовом представлении)
key 'q'sege quit      ; если key == 'q', перейти на quit
key 'q'mesege loop    ; если key != 'q', перейти на loop
```

**Ограничение:** Условные переходы работают **только с числами** (включая ASCII-коды символов). Строковые переменные сравнивать нельзя.

## Коды ошибок

| Код | Описание |
|---|---|
| 1 | Type mismatch (несоответствие типов в операции) |
| 2 | Unknown suffix (неизвестный суффикс) |
| 5 | Variable not found (переменная не найдена при чтении) |
| 7 | Type conflict (попытка изменить тип переменной) |
| 8 | Variable table full (превышен лимит 8 переменных) |
| 9 | Label not found (метка для перехода не найдена) |
| 10 | Missing target (отсутствует метка в условном переходе) |
| 11 | Return stack empty (`return` вне функции) |
| 12 | Call stack overflow (глубина вызовов > 8) |
| 13 | Array syntax error (ошибка в обращении к массиву) |
| 14 | Array already exists (массив с таким именем уже есть) |
| 15 | Array table full (превышен лимит 4 массивов) |
| 16 | Array not found (массив не объявлен) |
| 17 | Array index out of bounds (индекс вне диапазона) |

## Ограничения текущей версии

- **Максимум 8 переменных** одновременно
- **Максимум 4 массива** одновременно
- **Максимум 8 меток** в программе
- **Максимум 8000 байт** исходного кода
- **Нет ввода с клавиатуры** (INPUT не реализован)
- **Только сложение** (`-is`/`-es`), нет `-`, `*`, `/`
- **Нет работы с портами** (PEEK/POKE)
- **Нет файлового I/O**
- **Нет графики**

## Не реализовано (из полной спецификации)

Следующие возможности описаны в спецификации, но **пока не работают** в v0.1i:

- ❌ Сингармонизм в именах переменных (тип определяется контекстом)
- ❌ Модули (`INCLUDE 'math.alf'`)
- ❌ Суффикс `-dan` / `-den` (чтение из памяти/портов)
- ❌ Суффиксы `-saka` / `-seke` (условный вывод)
- ❌ Суффиксы `-sadan` / `-seden` (условное чтение)
- ❌ Суффикс `-ganca` / `-gence` (циклы WHILE)
- ❌ Суффикс `-gan` / `-gen` (FOR EACH)
- ❌ Частицы `yuksa`, `cakli`, `xatle`, `yuk`
- ❌ Отрицание `-mas` / `-mes` как отдельный оператор
- ❌ Логические связки `həm` (AND), `yaki` (OR)
- ❌ Операции сравнения `>`, `<`, `>=`, `<=` (только `==` и `!=`)
