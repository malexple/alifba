# Älifba (Алифба)

«Алифба» — название алфавита во всех тюркских языках (от «алиф» + «ба» — первые буквы арабской азбуки). Язык, построенный на буквах и их гармонии — минималистичный интерпретатор/компилятор для DOS/FreeDOS, умещающийся в 4 КБ.

Расширение исходников: `.alf`. Исполняемый файл движка: `alifba.com`.

## Статус реализации

**v0.1i — интерпретатор, стабильно работает.**

Поддерживается:
- Числовые и строковые переменные, присваивание, сложение/конкатенация с суффиксами `-is/-es`.
- `printka`/`printke` — вывод числа/строки (падеж `-ka/-ke`, Allativus).
- `-saga/-sege` и `-masaga/-mesege` — условный и отрицательный условный `GOTO` (Conditionalis + Dativus).
- `-ga/-ge` — безусловный `GOTO`.
- `-lik/-lek` — `CALL` подпрограммы, `RETURN` через стек вызовов (глубина до 8).
- `-lar/-ler` — массивы: объявление (`5lar scores`), чтение/запись по индексу (`scores[0] = 10`), контроль выхода за границы.
- Метки (`label:`), комментарии (`;`).
- Коды ошибок `ERR 1`–`ERR 17` (несовпадение типов, переполнение таблиц, метка не найдена и т.д.) — двузначные, через единый `report_error`.

Запуск: `alifba.com program.alf`

**v0.2 — AOT-компилятор (флаг `/c`) — в разработке, требует пересмотра архитектуры.**

Первая попытка добавить `/c program.alf` → `program.com` показала критическую проблему: наивная генерация кода дублирует всю логику разбора грамматики (`process_line` и отдельный `codegen_line` для каждой конструкции), что почти сразу привело к рассинхронизации и раздутию размера файла. План на пересборку — см. `ROADMAP.md`: общий слой `parse_statement`, разделяющий разбор строки от того, что с ней делать (выполнить сейчас или сгенерировать байты).

Перед реализацией нужно зафиксировать бюджет памяти и объём языка для первой версии компилятора — открытые вопросы см. в `ROADMAP.md`.

## Философия языка

Älifba построен на грамматике тюркских (в первую очередь татарского) языков: суффиксы-падежи заменяют ключевые слова и управляющие конструкции других языков программирования. У каждого суффикса есть **твёрдая** (для чисел) и **мягкая** (для строк) форма — это одновременно система типов (тип определяется по гласной в суффиксе, без отдельной таблицы типов) и способ уместиться в 4 КБ (парсер смотрит только на последнюю гласную суффикса, а не разбирает слово целиком).

### Таблица падежей

| Падеж | Твёрдая | Мягкая | Аналог в Basic/Си | Пример |
|---|---|---|---|---|
| Conditionalis | `-sa` | `-se` | `IF ... THEN` | `age 18sa` |
| Allativus | `-ka` | `-ke` | `PRINT`, `POKE` | `"Hi" printka` |
| Ablativus | `-dan` | `-den` | `PEEK`, `READ` | `portdan` |
| Pluralis | `-lar` | `-ler` | `DIM`, `ARRAY` | `5lar scores` |
| Negativus | `-mas` | `-mes` | `NOT`, `!=` | `statusmas` |
| Prolativus | `-ganca` | `-gence` | `WHILE`, `UNTIL` | `loopganca` |
| Participium | `-gan` | `-gen` | `FOR EACH` | `itemgan` |
| Comitativus | `-is` | `-es` | конкатенация | `text1 text2es` |
| Abstractus | `-lik` | `-lek` | `SUB`, `FUNC` | `summalik` |
| Dativus | `-ga` | `-ge` | `GOTO`, `CALL` | `startga` |

### Слитные суффиксы (условие + действие в одном токене)

| Операция | Если РАВНО | Если НЕ РАВНО | Что делает в x86 |
|---|---|---|---|
| Переход | `-saga` / `-sege` | `-masaga` / `-mesege` | `CMP` + `JE`/`JNE` |
| Вывод | `-saka` / `-seke` | `-masaka` / `-meseke` | `CMP` + условная запись |
| Ввод | `-sadan` / `-seden` | `-masadan` / `-meseden` | `CMP` + условное чтение |

Полная грамматика, разбор архитектурных решений (валидация сингармонизма, формат модулей `.alf`, таблица операторов) — см. `README-2.md`.

## Сборка

```
fasm alifba_v0_1i.asm alifba.com
```

Тестирование — только в DOSBox или FreeDOS (64-битная Windows не запускает 16-битные `.COM` напрямую).
